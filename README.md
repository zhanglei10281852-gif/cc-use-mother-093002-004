# 中文职业能力互认

本项目提供职业标准、能力单元和证明材料的基础领域契约，并在此基础上实现
职业能力互认服务：把国家或机构标准、能力单元、课程成果、实操证据与证书
版本建立映射，支持评审、异议复议、标准升级与人事时点查询。

## 模块

- `contracts`：版本化实体与证据的基础契约
- `catalog`：能力单元、证书版本、持证记录、课程成果、岗位画像
- `evidence`：实操证据台账（内容指纹防重、有效期、使用次数上限）
- `mapping`：互认映射登记处与标准升级影响分析
- `review`：评审案件、四类决定、利益冲突回避、异议与复议
- `recognition`：只增不改的结论台账与人事时点查询
- `service`：组合上述模块的服务门面

## 关键规则

- 同名等级不代表相同实操能力：互认以证书版本为键，而非等级名称
- 评审组可作出等同、部分等同、附加考核、不予互认四类决定；利益冲突
  回避留痕，已回避者不得投票
- 已生效结论不可覆盖；异议触发复议案件，复议以新结论取代旧结论，
  原结论在复议结案前保持有效，历史记录全部保留
- 标准升级只追加新记录：继续有效的映射平移到新版本，终止的映射退休，
  相关结论随之平移或失效；升级影响分析列出需补充证明的持证人
- 结论有效期不超过映射有效期与证书有效期：旧证书到期后结论自然失效，
  持证人按统一规则补证续期
- 同一证据不得借重复提交绕过有效期或使用次数：换号重报被拦截，
  同一案件重复提交幂等，跨案件使用受次数上限约束
- 并行评审通过乐观版本号拦截，不能覆盖已生效结论
- 人事部门输入申请人与任一历史日期，`assess` 返回当时可认可的岗位、
  缺失能力、待复议事项及所依据的标准版本

    python -m unittest discover -s tests -v

    python -m compileall -q src tests run_cli.py
